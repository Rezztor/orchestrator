# Rezztor Orchestrator

The enterprise agent that takes a prompt and orchestrates infrastructure and cloud work across Rezztor's products
and the customer's estate: discover, plan, get approval, execute through plugins, verify, report.

Design stage.

- [`PLAN.md`](PLAN.md): research of five open-source agent harnesses, the architecture, guardrails, agent
  protection, plugin contract, approvals, audit, multi-tenancy, roadmap and the open decisions.
- [`design/index.html`](design/index.html): the same design as a page with architecture diagrams. Open it in a
  browser.
