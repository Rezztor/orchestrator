# Security

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a
public issue or pull request for it.

Tell us what is affected, how to reproduce it, and what an attacker gains. We acknowledge a report within three working
days, agree a disclosure date with you, and credit you in the advisory unless you prefer not to be named.

Fixes go into `main` and the newest release, and its images on `ghcr.io/rezztor`.
